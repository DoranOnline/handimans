## 3. צד לקוח — מסכים

### 3.1 חיפוש (`#/customer/search`)
| אזור | תוכן |
|---|---|
| כותרת | "מי מגיע אליי?" + הסבר קצר |
| צ׳יפים | 10 קטגוריות, ברירת מחדל "הכול" |
| רדיוס | סליידר 1–30 ק״מ, עיגול חי על המפה |
| דחיפות | דחוף / היום / השבוע / גמיש |
| מיון | התאמה / מרחק / דירוג / מחיר |
| כרטיס | אווטאר, שם, מאומת, מקצוע, ניסיון, שכונה, דירוג, מרחק, זמן תגובה, טווח מחיר, מחיר קריאה, זמינות, % התאמה, כפתור "בקש הצעה" |
| מפה | סיכות לפי קטגוריה, נקודת עבודה draggable, לחיצה מזיזה את הנקודה |

מצבים: טוען · תוצאות · ריק ("אין בעלי מקצוע בטווח" + הגדלת רדיוס) · שגיאת מיקום (נפילה לשכונה) · מפה לא זמינה (רשימה בלבד).

### 3.2 בקשות שלי (`#/customer/requests`)
רשימת בקשות עם סטטוס, תיאור מקוצר, זמן יחסי ומספר הצעות. לחיצה פותחת פירוט מלא.

### 3.3 פירוט בקשה (מודאל)
- כותרת, כתובת, זמן, תגי דחיפות/תקציב/תמונות.
- תיאור מלא.
- אם נוצרה עבודה: ציר זמן (אושרה → התחילה → הסתיימה) + צ׳אט + דירוג.
- השוואת הצעות: מחיר, זמן הגעה, אחריות, דירוג, מרחק, הודעה, כפתור אישור.

### 3.4 צ׳אט (`#/customer/chat`)
רשימת שיחות + חלון הודעות + קלט. הודעות "שלי" בצד ימין בכ navy, "שלהם" בלבן. אינדיקטור לא-נקרא.

### 3.5 דירוג (מודאל)
5 כוכבים, טקסט חופשי, אפשרות תמונות. נפתח רק אחרי `job.status = completed`.

### 3.6 מצבים חריגים
| מצב | התנהגות |
|---|---|
| אין מיקום | בקשת הרשאה → נפילה לעיר/שכונה |
| כתובת לא נמצאה | סיכה ידנית + הודעה |
| 0 תוצאות | הגדלת רדיוס בלחיצה |
| בקשה כפולה | הגבלת 3 ביום + הודעה |
| בעל מקצוע ביטל | הצעה חלופית + החזר 100 ₪ ליתרה |
| עבודה במחלוקת | כפתור "פתיחת תלונה" + קיפאון תשלום |

## 4. צד בעל מקצוע — מסכים

### 4.1 סקירה (`#/pro/dashboard`)
4 KPI (פניות, המרה, הכנסה, דירוג) · פניות מתאימות · עבודות קרובות · ארנק · גרף 12 חודשים · משפך · מצב חשבון.

### 4.2 פניות חדשות (`#/pro/leads`)
רק בקשות פתוחות בקטגוריה ובתחום הרדיוס. לכל פנייה: מקצוע, דחיפות, מרחק, תקציב, תיאור, כתובת, זמן, תמונות, כפתור "שלח הצעה" או תג "הצעה נשלחה".

### 4.3 שליחת הצעה (מודאל)
מחיר · זמן הגעה · אחריות בחודשים · הודעה · עלות 100 ₪ לפנייה. בדיקת יתרה לפני פתיחה; אם אין — מודאל טעינה.

### 4.4 ההצעות שלי (`#/pro/offers`)
טבלה: בקשה, לקוח, מחיר, הגעה, אחריות, זמן, סטטוס (ממתינה/אושרה/לא נבחרה/פגה).

### 4.5 עבודות ויומן (`#/pro/jobs`)
לוח שבועי + "הבא בתור" + טבלת כל העבודות. מעבר סטטוס: מתוזמן → בביצוע → הושלם.

### 4.6 פרופיל ואזור (`#/pro/profile`)
כרטיס פרופיל · מדדי אמינות · מסמכים ואימות · מפת אזור שירות עם רדיוס · תמחור · זמינות · התראות.

### 4.7 יתרה וחיובים (`#/pro/credits`)
יתרה בשקלים · טעינה (500/1,000/2,500 ₪) · תנועות עם יתרה אחרי כל תנועה · הבהרה: פרסום הוא הוצאה של בעל המקצוע, לא מוצר שלנו.

### 4.8 דירוגים (`#/pro/reviews`)
ממוצע · התפלגות 1–5 · כל ביקורת עם תגובה אפשרית.

### 4.9 מצבים חריגים
| מצב | התנהגות |
|---|---|
| אין יתרה | חסימת שליחה + מודאל טעינה |
| מחוץ לאזור | הפנייה לא מוצגת כלל |
| מסמך פג תוקף | התראה 30 יום מראש + חסימת קטגוריה מסוכנת |
| 3 ביטולים | ירידת דירוג + אזהרה |
| עבודה במחלוקת | קיפאון תשלום + אפשרות תגובה |

## 5. צד מנהל — מסכים

### 5.1 סקירה (`#/admin/overview`)

### 5.3 מחלוקות (`#/admin/disputes`)

### 5.4 משתמשים (`#/admin/users`)
בעלי מקצוע עם חיפוש חי, השעיה/שחזור; לקוחות עם היסטוריית בקשות והוצאה.

### 5.5 קטגוריות (`#/admin/catalog`)

### 5.6 יתרות ותשלומים (`#/admin/credits`)
סה״כ יתרות פתוחות · נטען/חויב · כל התנועות · התאמה ידנית עם הנמקה.

### 5.7 יומן פעילות (`#/admin/audit`)

### 5.8 הגדרות (`#/admin/settings`)
אזורי השקה · SLA · מצב תחזוקה · פרטיות ואבטחה.

## 6. מכונות מצב

### בקשה
```
open ──► matched ──► scheduled ──► in_progress ──► completed
  │                                                  
  ├──► expired (48ש׳ ללא הצעות)
  └──► cancelled
```

### הצעה
```
sent ──► accepted
  ├──► declined (נבחר אחר)
  ├──► expired (24ש׳)
  └──► withdrawn
```

### עבודה
```
scheduled ──► in_progress ──► completed
     │              │
     └──► cancelled └──► disputed ──► resolved
```

### אימות
```
draft ──► pending ──► approved
              └──► rejected ──► pending (הגשה חוזרת)
```

### מחלוקת
```
open ──► resolved (החזר / זיכוי / דחייה)
  └──► escalated (מעל 72ש׳)
```

## 9. נגישות

- כל כפתור עם `aria-label` או טקסט גלוי.
- `aria-pressed` על צ׳יפים וסגמנטים, `aria-current="page"` על ניווט.
- מודאל: `role="dialog"`, `aria-modal`, סגירה ב-Escape ובלחיצה על הרקע.
- ניגודיות ≥ 4.5:1 לכל טקסט; פוקוס גלוי.
- ניווט מקלדת מלא; כרטיסים עם `tabindex` ו-Enter/Space.
- טפסים עם `<label for>` אמיתי, שגיאות טקסטואליות ולא רק צבע.

## 12. צד קבלן — מסכים (ניהול עסק)

עסק עם צוות מנהל את העבודה שלו בתוך הפלטפורמה: יומן, תורים, תור המתנה, צוות ועמוד ציבורי. זה מה שמבדיל אותו מבעל מקצוע עצמאי — הוא לא מחפש עבודה, הוא מתזמן עבודה.

### 12.1 סקירה (`#/contractor/dashboard`)
| אזור | תוכן |
|---|---|
| KPI | תורים היום · ניצולת צוות · הכנסה מתוכננת היום · לקוחות חוזרים |
| יומן היום | שורה לכל תור: שעה, לקוח, שירות, איש צוות, מחיר, סטטוס |
| תור המתנה | 3 הוותיקים + כפתור "שבץ" |
| ביקוש | 5 השירותים המבוקשים עם יחס |

### 12.2 יומן ותורים (`#/contractor/calendar`)
| אזור | תוכן |
|---|---|
| רשת | 7 ימים × 10 שעות (08:00–17:00), עמודת שעה קבועה |
| משבצת | תור צבוע לפי איש צוות; מעל הקיבולת מסומנת כ"מלא" |
| לחיצה על משבצת ריקה | מודאל קביעת תור עם יום ושעה ממולאים |
| לחיצה על תור | כרטיס תור + מעברי סטטוס |
| מקרא | צבע לכל סטטוס |

### 12.3 תור המתנה (`#/contractor/queue`)
לקוחות בלי תור, ממוינים לפי דחיפות וזמן המתנה · שיבוץ בלחיצה אחת · הסרה בשיבוץ.

### 12.4 צוות (`#/contractor/team`)
כרטיס לאיש צוות: דירוג, עבודות, תורים היום מול קיבולת, פס עומס, השבתה/הפעלה, הוספת תור, חיוג. הוספת איש צוות חדש במודאל.

### 12.5 העמוד הציבורי (`#/contractor/page`)
תצוגה מקדימה של העמוד שהלקוח רואה: שם, סלוגן, אימות, ביטוח, דירוג, שירותים ומחירים, שעות, אזור שירות, כפתורי "קבע תור" ו"התקשר". לצידו: צפיות, שיחות, תורים מהעמוד, המרה, ומקורות התנועה. קישור להעתקה ותצוגת לקוח במודאל.

### 12.6 פניות ולידים (`#/contractor/leads`)
פניות פתוחות במקצועות העסק ובטווח הרדיוס, ממוינות לפי מרחק · לקיחה ב-100 ₪ · לאחר לקיחה הכפתור הופך ל"קבע תור".

### 12.7 הגדרות העסק (`#/contractor/settings`)
פרטי עסק · שעות פעילות לכל יום · משך תור · קיבולת במקביל · פיקדון · אישור אוטומטי · רדיוס שירות.

### 12.8 מכונת מצב — תור
```
pending ──► confirmed ──► in_progress ──► done
   │            │              │
   └────────────┴──────────────┴──► cancelled
                └──► no_show
```
מעבר ל-`done` פותח דירוג ללקוח. `no_show` מסמן את הלקוח ומשפיע על עדיפות בתור המתנה.

### 12.9 מצבים חריגים
| מצב | התנהגות |
