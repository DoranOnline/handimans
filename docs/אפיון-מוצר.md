# HANDIMANS — אפיון מוצר v1.0

> מרקטפלייס גיאוגרפי לבעלי מקצוע בבית. הלקוח מסמן מקום, בוחר רדיוס — ורואה רק מי שבאמת מגיע אליו.

---

## 1. תקציר במשפט

HANDIMANS היא אפליקציה שבה בעל מקצוע מפרסם את עצמו לפי **אזור שירות ורדיוס**, ולקוח באזור מקבל רק בעלי מקצוע רלוונטיים, זמינים ומאומתים — עם מחיר, דירוג וזמן תגובה ידועים מראש.

ההבדל המרכזי מיד2/פייסבוק/קבוצות שכונתיות: **המפה היא מסך הבית, והרדיוס הוא הפילטר הראשון — לא הקטגוריה.**

## 3. קהלי יעד

### בעלי מקצוע (Supply)
חשמלאי · אינסטלטור · טכנאי מיזוג · נגר · צבעי · רצף · גבסאי · מנעולן · אלומיניום · ניקיון · גינון · מובילים · תיקוני בית כלליים · שיפוצים קטנים.

פילוח:
- **עצמאי יחיד** (עוסק פטור/מורשה) — 70% מהשוק, רגיש למחיר, עובד מהנייד.
- **צוות קטן** (2–5 עובדים) — צריך יומן וניהול פניות.
- **חברה מסודרת** — מחפשת נפח, מוכנה לשלם מנוי.

### קבלנים / עסקים עם צוות (Supply מורחב)
- חברה עם 2–20 אנשי מקצוע: שיפוצים, מיזוג, אינסטלציה, חשמל.
- הכאב שלהם אינו "למצוא עבודה" אלא **לתזמן עבודה**: מי פנוי, איזה תור נכנס, מי לא הגיע, מה קורה כששני לקוחות רוצים 09:00.
- הם כבר משלמים על פרסום (Google/Meta) ולא יודעים מה חזר ממנו. העמוד הציבורי נותן להם מדידה: צפיות, שיחות, תורים.
- הם משלמים 100 ₪ לפנייה בדיוק כמו עצמאי, אבל שווים יותר: קיבולת גדולה, פחות נשירה, יותר תורים לחודש.

### לקוחות (Demand)- בעלי דירות ובתים פרטיים (35–65), בעיקר בערים.
- שוכרים צעירים — תיקונים קטנים, דחוף.
- ועדי בית וחברות ניהול — נפח חוזר, B2B.
- עסקים קטנים — משרדים, מסעדות, חנויות.

## 4. הצעת הערך

**ללקוח:** "בעל מקצוע מאומת, במרחק 4 ק״מ ממך, פנוי מחר ב-9:00, טווח מחירים 350–500 ₪ — ותוך 20 דקות יש לך 3 הצעות."

**לבעל המקצוע:** "קבע את אזור העבודה שלך פעם אחת. קבל רק פניות בתוך הרדיוס שבחרת, עם תמונה ותיאור, ותשלם רק על ליד שמתאים לך."

שלושת עמודי האמון:
1. **אימות** — ת״ז, עוסק, ביטוח אחריות מקצועית, תעודות מקצוע.
2. **שקיפות** — טווח מחירים, מחיר קריאה, זמן תגובה ממוצע, שיעור קבלה.
3. **הוכחה** — דירוג רק אחרי עבודה שהושלמה, עם תמונות לפני/אחרי.

## 5. עקרון המוצר: רדיוס, לא רשימה

```
לקוח מסמן נקודה על המפה
        ↓
בוחר קטגוריה + דחיפות
        ↓
גורר רדיוס (1–30 ק״מ)
        ↓
רואה רק בעלי מקצוע שהוגדרו כנותני שירות באזור הזה
        ↓
ממיין לפי: מרחק / דירוג / זמינות / מחיר
```

**מודל אזור שירות לבעל המקצוע** (שלוש אפשרויות, לפי רמת):
- **בסיסי:** נקודת מוצא + רדיוס בק״מ.
- **מתקדם:** עד 5 נקודות/רדיוסים (בית + מחסן + שכונות).
- **Pro:** פוליגון על המפה — "כל גוש דן למעט הרצליה פיתוח".

## 6. מסעות משתמש

### 6.1 לקוח — "יש לי נזילה במטבח"
1. נכנס, מאשר מיקום (או מקליד כתובת / שכונה).
2. בוחר "אינסטלציה" + "דחוף — היום".
3. המפה מציגה סיכות בטווח; כרטיסים למטה עם מרחק, דירוג, טווח מחיר וזמינות.
4. לוחץ "בקש הצעה" → מוסיף תמונה, תיאור קצר, חלון זמן.
5. הבקשה נשלחת ל-5–8 בעלי מקצוע מתאימים בטווח.
6. תוך 20 דקות מתקבלות 3 הצעות: מחיר, זמן הגעה, אחריות.
7. משווה בטבלה, מאשר הצעה → צ׳אט נפתח.
8. סיום עבודה → תשלום (V2) → דירוג + טיפ אופציונלי.

### 6.2 בעל מקצוע — "אני רוצה עוד עבודות באזור שלי"
1. הרשמה בטלפון + OTP.
2. מילוי פרופיל: מקצועות, שנות ניסיון, אזור שירות, שעות, מחיר קריאה, טווח מחירים, תמונות עבודות.
3. העלאת מסמכים → בדיקה אוטומטית + אישור אדמין (SLA 24 שעות).
4. הגדרת התראות: push / SMS / וואטסאפ.
5. קבלת בקשה בטווח → "שלח הצעה" בתבנית מהירה (60 שניות).
6. ניהול יומן, סימון "התחלתי / סיימתי", בקשת דירוג.
7. דשבורד: פניות, שיעור המרה, הכנסה, דירוג.

### 6.3 קבלן — "יש לי ארבעה אנשי צוות ואני לא יודע מי פנוי"
1. נכנס לסקירה ורואה 5 תורים היום, ניצולת 23% ו-4 ממתינים לשיבוץ.
2. פותח את היומן השבועי, לוחץ על משבצת ריקה ב-15:00 — מודאל תור עם יום ושעה ממולאים.
3. שולח את אישור התור ללקוח, התור נכנס ליומן של איש הצוות.
4. עובר לתור המתנה, משבץ לקוח דחוף מהבוקר לתור שהתפנה.
5. בודק את העמוד הציבורי: 1,840 צפיות, 96 שיחות, 41 תורים — ומעתיק את הקישור לקמפיין שלו.
6. לוקח פנייה חדשה באזור ב-100 ₪ ומתזמן אותה ישירות.

### 6.4 אדמין
אישור בעלי מקצוע · ניהול מחלוקות · חסימות · החזרי קרדיטים · דוחות · תוכן קטגוריות.

## 9. לוגיקת גיאו — הלב הטכני

```sql
-- הרחבה
create extension if not exists postgis;

-- אזור שירות: נקודה + רדיוס
alter table pro_profiles
  add column base_location geography(Point, 4326);
create index on pro_profiles using gist (base_location);

-- שאילתת "מי מגיע אליי"
select p.*,
       st_distance(p.base_location, :job_point) as distance_m
from pro_profiles p
join pro_trades pt on pt.pro_id = p.id
where pt.trade_id = :trade_id
  and p.status = 'active'
  and st_dwithin(p.base_location, :job_point, p.service_radius_m)
order by distance_m
limit 50;
```

**ניקוד דירוג חכם** (לא רק מרחק):

```
score = 0.35 * proximity      // 1 - distance/radius
      + 0.25 * rating_norm    // (rating - 3) / 2
      + 0.15 * availability   // פנוי בחלון המבוקש
      + 0.15 * reliability    // acceptance rate * completion rate
      + 0.10 * responsiveness // 1 - response_minutes/120
```

**Geocoding:** MapTiler / Google Places, עם cache מקומי. אם הכתובת לא נמצאה — נופלים לשכונה ומבקשים מהלקוח להזיז את הסיכה.

**פרטיות מיקום:** לא מציגים כתובת מדויקת לבעל המקצוע עד אישור הצעה. במפה מוצג "מרכז שכונה" + רדיוס מטושטש (snapping ל-250 מ׳).

## 10. אמון, בטיחות ואיכות

- **אימות מדורג:** טלפון → ת״ז → עוסק → ביטוח → תעודה מקצועית. כל שלב פותח יכולות (למשל: ללא ביטוח אין קטגוריית חשמל/גז).
- **בדיקת מסמכים:** OCR + בדיקת תוקף אוטומטית, ואדמין מאשר. SLA 24 שעות.
- **דירוג אמיתי:** רק אחרי `job.completed`. אין מחיקת ביקורות שליליות — רק תגובה.
- **מדיניות ביטולים:** חינם עד 12 שעות לפני; אחר כך דמי ביטול מוגדרים.
- **מחלוקות:** פתיחת תלונה → קיפאון תשלום → אדמין מכריע תוך 72 שעות.
- **חסימה:** 3 ביטולי עבודה אחרונים = ירידה בדירוג; הונאה = חסימה מיידית.
- **אחריות משפטית:** הפלטפורמה מתווכת; תנאי השימוש מפרידים בין הצדדים. בנוסף — "אחריות HANDIMANS" אופציונלית ל-30 יום כפיצ׳ר עתידי.

## 12. מונטיזציה

| מקור | מחיר | שלב |
|---|---|---|
| **פנייה (ליד)** | **100 ₪ לפנייה** — נגבה מבעל המקצוע רק כשהוא שולח הצעה בפועל | MVP |
| **מנוי Pro** | 149–299 ₪/חודש — חשיפה מוגברת, סטטיסטיקות | V2 |
| **עמלת תשלום** | 5–8% על עסקה | V2 |
| **B2B** | 990–2,900 ₪/חודש לוועדי בית/חברות ניהול | V3 |

**פרסום אינו מקור הכנסה שלנו.** קמפיינים ממומנים של בעלי מקצוע (Google, Meta, אינסטגרם) הם הוצאה שלהם. הפלטפורמה לא מוכרת פרסום, לא מריצה מודעות עבורם ולא גובה עליהן. מה שכן — הם מקבלים מאיתנו מדידה: כמה פניות הגיעו, מכמה עבודות נסגרו, ומה עלה כל ליד.

**למה 100 ₪ לפנייה ולא עמלה:** בעלי מקצוע בישראל מתנגדים לעמלה על עבודה שהם סגרו לבד. פנייה = תשלום על שיווק, לא על הכנסה. קל יותר למכור, ומייצר הכנסה מהיום הראשון.

**כלכלת יחידה (100 ₪ לפנייה):**
- פנייה = 100 ₪ · עבודה ממוצעת = 600 ₪ → עלות פנייה = 17% משווי עבודה.
- המרה 1:3 (פנייה→עבודה) → 300 ₪ עלות ליד לכל עבודה = 50% מהעבודה. המרה 1:2 → 200 ₪ = 33%.
- המסקנה: 100 ₪ לפנייה עובד רק כשהפנייה מדויקת. לכן המיקוד הוא רדיוס + מקצוע + דחיפות, ולא נפח פניות.
- בעל מקצוע פעיל: 10–15 פניות בחודש = 1,000–1,500 ₪/חודש = 12,000–18,000 ₪ בשנה.
- CAC יעד ≤ 600 ₪ → LTV/CAC ≈ 20–30.
