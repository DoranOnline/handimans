# החלטת סטאק טכנולוגי — HANDIMANS

> **המלצה בשורה אחת:** TypeScript אחד מקצה לקצה — Next.js לווב, Expo לנייטיב, Supabase לבקאנד ולגיאו. שפה אחת, סכימת נתונים אחת, צוות אחד.

---

## 1. למה TypeScript ולא משהו אחר

| שיקול | המשמעות ל-HANDIMANS |
|---|---|
| **שפה אחת לכל המקומות** | אותו קוד טיפוסים משמש בווב, באפליקציה ובשרת. פחות באגים, פחות עבודה כפולה. |
| **גיאו ב-SQL** | PostGIS עושה את חישובי הרדיוס במהירות ובאיכות שאין לשום ORM. TypeScript רק קורא לתוצאה. |
| **מהירות פיתוח** | Next.js + Supabase = MVP תוך שבועות, לא חודשים. |
| **כישרונות** | קל למצוא מפתחים בישראל. גם מתחילים. |
| **כלי AI** | המודלים הכי טובים בקוד TypeScript/React. פחות חיכוך איתך בהמשך. |
| **עלות** | Vercel + Supabase חינם עד נפח רציני. |

## 2. הסטאק המומלץ

### פרונט-אנד
| רכיב | בחירה | למה |
|---|---|---|
| Framework | **Next.js 15 (App Router)** | SSR/SEO לפרופילים, Server Actions, מהיר |
| שפה | **TypeScript** (strict) | בטיחות טיפוסים |
| עיצוב | **Tailwind CSS v4 + shadcn/ui** | מהיר, נגיש, RTL מובנה |
| RTL | `dir="rtl"` + logical properties | עברית וערבית מאותו קוד |
| מפה | **MapLibre GL JS** + OSM/MapTiler | חינמי, מהיר, ללא חיוב לפי צפייה |
| טפסים | React Hook Form + Zod | ולידציה משותפת עם השרת |
| State | TanStack Query + Zustand | cache לשרת + state מקומי |

### בקאנד ונתונים
| רכיב | בחירה | למה |
|---|---|---|
| DB | **Postgres + PostGIS** (Supabase) | `ST_DWithin` הוא בדיוק הפיצ׳ר שלנו |
| Auth | Supabase Auth (Phone OTP) | טלפון זה הזהות בישראל |
| Storage | Supabase Storage | תמונות עבודות ומסמכים |
| Realtime | Supabase Realtime | צ׳אט והתראות בזמן אמת |
| הרשאות | **Row Level Security** | אבטחה ברמת השורה, לא בקוד |
| פונקציות | Supabase Edge Functions (Deno/TS) | לוגיקה רגישה: דירוגים, יתרות וחיובי פניות, התראות |
| ולידציה | Zod shared package | אותו סכימה בצד לקוח ושרת |

### מובייל
| שלב | בחירה |
|---|---|
| MVP | **PWA** — התקנה למסך הבית, push, מצלמה. אפס חנויות. |
| V2 | **Expo (React Native)** — אותו TypeScript, אותו Supabase client, אותו עיצוב. |

## 6. התחלה מהירה (פקודות)

```bash
# 1. פרויקט Next.js
pnpm create next-app@latest handimans --ts --tailwind --app --eslint

# 2. Supabase מקומי
pnpm add supabase --save-dev
pnpm supabase init
pnpm supabase start

# 3. חבילות ליבה
pnpm add @supabase/supabase-js @supabase/ssr zod react-hook-form
pnpm add maplibre-gl @vis.gl/react-maplibre
pnpm add @tanstack/react-query zustand

# 4. הרצת סכימת ה-DB
pnpm supabase db reset   # מריץ את db/schema.sql
```

## 7. כללי עבודה

- **TypeScript strict** — אין `any` בקוד עסקי.
- **Server-first** — כל לוגיקה רגישה בצד שרת. הלקוח לא מחשב מחירים, יתרות או דירוגים.
- **Zod בכל גבול** — כל קלט מהמשתמש עובר סכימה.
- **RLS לפני כל טבלה** — לא משחררים טבלה בלי policy.
- **מיגרציות בלבד** — אין שינוי ידני בפרודקשן.
- **Preview deploy לכל PR** — בודקים על דאטה אמיתי.
- **נגישות מהיום הראשון** — ת״י 5568, לא בדיקה בסוף.

## 8. מה הייתי עושה בשבוע הראשון

1. `schema.sql` + PostGIS + RLS — השלד שכל השאר נשען עליו.
2. Auth בטלפון + OTP — הזהות לפני הכול.
3. מפה עם רדיוס וסיכות — הפיצ׳ר שהופך את הרעיון למוצר.
4. פרופיל בעל מקצוע + העלאת מסמכים — צד ההיצע.
5. בקשה אחת מקצה לקצה — "יש נזילה" עד "נשלחה הצעה". זה ה-MVP האמיתי.
